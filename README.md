# Code File & Function Tree

Дърво в Activity Bar-а на VSCode с файловете от workspace-а (`.pl`, `.pm`, `.cgi`, `.html`, `.js`, `.css`), а под всеки `.pl`/`.pm`/`.cgi`/`.js` файл — функциите (Perl `sub`, JS функции/методи), дефинирани в него.

## Какво прави

- **Дърво**: папки → файлове → функции, вложени едно в друго.
- **Двоен клик върху файл** — отваря файла. Единичен клик само разгъва/свива клона му в дървото.
- **Клик върху функция** — отваря файла с курсора в началото на функцията.
- **Синхронизация с курсора** — докато местиш курсора в отворен файл, функцията, в която се намираш, автоматично се маркира в дървото.
- Дървото се обновява при създаване/изтриване на файлове и при запис (за да прихване нови/премахнати функции).

## Отделен прозорец (за втори монитор)

Sidebar/Panel панелите на VSCode не се извличат в отделен прозорец. Затова има и втори начин да ползваш дървото — като таб в editor областта:

- Бутон **"Code Tree: Open in Editor Tab"** (иконата до refresh в заглавието на панела), или командата със същото име от Command Palette.
- Този таб е нормален editor tab — извлачваш го извън прозореца на VSCode точно както таб на файл, за да го сложиш на друг монитор.
- Има същото поведение (единичен/двоен клик, синхронизация с курсора), но е отделен, по-опростен UI (не е вграденият VSCode TreeView).

## Разпознаване на функции

Ползва се regex, не истински parser:

- Perl: `sub name { ... }`
- JS: `function name()`, `const name = function/() => {}`, методи в клас/обект (`name(...) {`)

Покрива обичайните случаи, но може да пропусне екзотични конструкции (напр. сигнатура на няколко реда).

## Известни ограничения

- Списъкът с разширения, които се показват, засега е фиксиран в кода (`.pl .pm .cgi .html .js .css`) — настройка за това предстои.
- `.html`/`.css` файловете се показват в дървото, но без вложени функции.
