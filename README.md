# Code File & Function Tree

Дърво в Activity Bar-а с файловете от проекта и функциите във всеки файл (Perl, JS/TS, shell и `<script>` в `.html`).

## Дървото

- **Двоен клик** върху файл го отваря, единичен — разгъва/свива. **Клик** върху функция отваря файла на нея.
- Функцията, в която е курсорът, се маркира в дървото.
- Функциите се обновяват, докато пишеш. В Perl файл с няколко пакета са групирани по пакет.
- **Десен клик**: Open to the Side, Reveal in Explorer View, Copy Name, Copy Relative Path.

## Навигация

- `F12` / `Ctrl`+клик — дефиницията на функцията (търси само във файлове на същия език). В Perl отваря и модула при `use Foo::Bar;` и скача директно до правилния `sub` при `Foo::Bar->new`, `Foo::Bar::helper()` или функция от същия файл.
- `Shift+F12` — всички места, където се среща функцията (Perl и shell).
- `Ctrl+T` — търсене на функция в целия проект; `Ctrl+Shift+O`, Outline и breadcrumbs — функциите в текущия файл (Perl и shell).
- `Alt+O` (**Code Tree: Open Selected File**) — отваря файла, чийто път е под курсора (`require "lib/Utils.pm"`, `<script src="js/app.js">`, `<TMPL_INCLUDE NAME=...>`, `source ./env.sh`). Ако има няколко съвпадения, показва списък.

## Настройки

| Настройка | По подразбиране | |
|---|---|---|
| `JChCodeTree.extensions` | Perl, JS/TS, shell, `.html`, `.css`, `.json` | Кои разширения се показват и как се търсят функциите в тях: `perl`, `js`, `html`, `sh`, `none` (без функции) или `hide`. Напр. `{ ".t": "perl", ".json": "hide" }` |
| `JChCodeTree.exclude` | `[]` | Glob шаблони за скриване, напр. `["**/logs", "tmp"]`. Спазва се и `files.exclude`. |
| `JChCodeTree.showHiddenFiles` | `false` | Показва файлове и папки, започващи с `.` |
| `JChCodeTree.showSymlinks` | `false` | Показва файлове и папки през symlink (тогава F12 и `Alt+O` може да дават дублирани резултати) |
| `JChCodeTree.autoUpdate` | `true` | Автоматично обновяване от GitHub |
| `JChCodeTree.autoUpdateIntervalHours` | `4` | През колко часа да проверява за нова версия; `0` — само при стартиране |

## Инсталиране и обновяване

Еднократно: изтегли последния `.vsix` от [version/](https://github.com/JekoCh/JChCodeTree/tree/master/version) и го инсталирай с **Extensions → … → Install from VSIX…**. След това новите версии се инсталират сами и се предлага Reload. **Code Tree: Check for Updates** проверява веднага.

## Ограничения

- Функциите се разпознават по шаблон, не с истински parser — екзотични конструкции (напр. сигнатура на няколко реда) може да се пропуснат.
- Краят на функция не се разпознава: за Outline тя стига до следващата.
- `Shift+F12` е текстово търсене — брои и срещания в коментари и стрингове.
- Наследяване в Perl (`use parent`/`@ISA`) не се проследява.
- Файл без разширение се показва само ако е shell скрипт (shebang на първия ред).
